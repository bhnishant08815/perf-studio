See how a website behaves when many people use it at the same time. Fill in the steps, press Run, then read the report.

Import API list

A Postman collection, an OpenAPI 3 or Swagger 2 file (JSON), or a list of {method, path}.

Or paste JSON

    Type part of a name, address, method or folder to narrow the list.

    Website and calls

    The start of every address in the test, for example https://test.example.com.

    Pages or API calls that each simulated person will visit, in order.

    Values the calls need

    Some calls have a gap such as :round_id. Type a real value from your test system once; it is used in every call that has that gap.

    Credentials (optional)

    Imported tokens are saved as plain text in this browser's storage, and credentials you type are written in plain text to the run files on this computer. Use disposable test accounts on non production systems. Hiding a value on screen is not encryption. Fixed credentials chosen here win over any Authorization header an imported call carries.

    Pick how the site knows which account is calling it.

    The address that signs in, called once before the test starts.

    The test account name to sign in with.

    The password of that test account.

    Where the login reply puts the pass that later calls send back.

    Advanced: field names and extra details

    What the login call names the account box, often email or username.

    What the login call names the password box.

    Anything else the login call needs, written as JSON.

    The token to send as the Bearer pass on every call.

    The header the site reads the key from, often X-Api-Key.

    The key itself, sent in that header on every call.

    The test account name sent with every call.

    The password of that test account.

    Sent with every call in the test. They never appear in the report.

    Kind of test

    Advanced: people, time, limits, graphs

    How much traffic?

    How many simulated people use the site at the very same moment.

    How long it takes to go from no one to the full number of people.

    How long the full number of people keep using the site.

    How long it takes for everyone to leave again.

    How long each person waits before the next call, like a real reader.

    Each number is one step; 1.5 means one and a half times the people above.

    What counts as good? (optional)

    Slowest 1 in 20 visits (p95) must finish faster than this.

    The share of calls allowed to fail before the test counts as failed.

    Clear a box to set no limit for it. With no limits the test never fails or stops early because of speed or errors.
