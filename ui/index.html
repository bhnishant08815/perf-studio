Perf Studio

See how a website behaves when many people use it at the same time. Fill in the steps, press Run, then read the report.

Import API list

A Postman collection, an OpenAPI 3 or Swagger 2 file (JSON), or a list of {method, path}.

    Website and calls

    Pages or API calls that each simulated person will visit, in order.

    Values the calls need

    Some calls have a gap such as :round_id. Type a real value from your test system once; it is used in every call that has that gap.

    Credentials (optional)

    Advanced: field names and extra details

    Sent with every call in the test. Use a test account, never a real person's details. They are saved in plain text on this computer and never shown in the report.

    Kind of test

    Advanced: people, time, limits, graphs

    How much traffic?

    What counts as good? (optional)

    Clear a box to set no limit for it. With no limits the test never fails or stops early because of speed or errors.
